关于我

我是雷洋，数字媒体艺术专业毕业，做过两年系统策划。工作中做战斗玩法和系统功能，平时喜欢自己搭关卡。

我最喜欢能让我绕路的地图。玩《耻辱》时，看到一扇守着人的正门，我会先抬头找窗户或阳台。《黑暗之魂》系列和《明末：渊虚之羽》里，我爱找那些从另一面打开的门，看看刚走过的一大段路究竟绕回了哪里。《密特罗德》的乐趣又有点不同，拿到新能力，我往往先想起之前过不去的那个岔口。

做史东薇尔城拆解时，我在 Unreal Engine 里把城墙、钥匙门和升降梯搭进白盒，再切到人物视角走一遍。俯视图上挨在一起的两条路，站到墙根可能根本看不见对方。这也是我喜欢动手搭关卡的原因。

我会持续跟进行业里的新工具和制作方法，先挑手头一个具体问题来试。现在我已经能熟练运用 Vibe Coding。写玩法说明或配置策划表时，我先定好规则和字段，用 Codex 协助整理内容、批量填表，再自己核对数值和触发条件。
