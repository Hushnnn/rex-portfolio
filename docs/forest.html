01 / OVERVIEW

项目概述

这是以《塞尔达传说：王国之泪》的探索体验为参考的森林场景关卡设计练习。基于阶梯状地形，将起点放在山脚、终点放在高处，通过植被遮挡、收集物和瞭望台逐步提供空间信息。以下内容来自我的关卡说明文档，描述的是设计意图与预期路线。

PROCESS / DESIGN

设计与过程

01 / 先给方向，再给全貌

前段山路以收集物和巡逻敌人构成初步体验。到达关键观察位置后，远处高塔进入视野，成为玩家能够持续识别的终点地标。

02 / 在瞭望台上形成选择

瞭望台提供区域信息：怪物营地、NPC 住处、武器库、补给区与 Boss 区。玩家先观察，再权衡风险与收益，选择下一步路线。

03 / 让任务与空间互相解释

清理怪物营地后与 NPC 交互，取得武器库钥匙和弓箭，再挑战独眼巨人，取得终点塔的开门道具。任务链将资源、战斗教学与最终目标连接起来。

04 / 给熟悉玩法的玩家另一条路

常规路径承担适应与教学作用；另一条路线可以更直接地抵达瞭望台。登上终点后回望来路，以高度变化强化完成探索的感受。
