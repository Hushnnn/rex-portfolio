# 雷洋 Rex 的作品集 · GitHub Pages

这个包是当前作品集的静态副本，首页在 docs/index.html。图片、字体、实机视频与简历都在 docs/assets/。可以先在本机打开首页预览。

## 第一次发布（免费方案）

1. 登录自己的 GitHub 账号，新建一个公开仓库，例如 rex-portfolio。免费 GitHub Pages 使用公开仓库，任何人都能浏览其中的网页及资源。
2. 把本包解压。在仓库的 Add file → Upload files 中上传 README.md 和整个 docs 文件夹，包括 docs/assets 下的内容。网站需要解压后的文件；只上传 ZIP 不会生成网站。使用 GitHub Desktop 提交文件也可以。
3. 在 Settings → Pages 选择 Deploy from a branch，分支 main，目录 /docs，点 Save。在 Pages 页面等待 GitHub 显示已发布的网址。
4. 在大陆网络关闭代理，分别用手机流量和家用宽带打开这个新网址。检查首页、史东薇尔详情、游戏封面和黄昏血族的站内视频。测试通过后再使用该地址投递。

## 自己更新内容

- 改个人介绍、作品卡片或游戏经历，编辑 docs/index.html。
- 改现有作品，在 docs/ 下打开同名 HTML 文件，新图放进 docs/assets/。
- 新增作品，复制一份类似的详情页，换掉标题、图片与说明，在首页“作品选集”增加通往它的卡片。如果使用“下一个作品”导航，同时更新相邻项目的链接。
- 也可以用 Codex 打开仓库所在的文件夹，用中文交代改动；检查后把修改提交到同一分支。GitHub Pages 会用同一个地址重新发布。后续应维护这个仓库，原 Sites 站单独编辑的内容不会自动同步过来。
